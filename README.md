# 📝 React Notes App

A simple and responsive Notes App built with **React**, **Vite**, and **Tailwind CSS**. Users can create and delete notes with an easy-to-use interface.

## 🚀 Features

- Add new notes
- Delete notes
- Responsive design
- Built with React Hooks (`useState`)
- Modern UI with Tailwind CSS

## 🛠️ Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript (ES6+)

## 📂 Installation

Clone the repository:

```bash
git clone https://github.com/Bhupendra-Kumar-1/react-notes-app.git
```

Go to the project folder:

```bash
cd react-notes-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
