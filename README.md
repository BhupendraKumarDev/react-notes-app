## 📖 Overview

**React Notes App** is a fast, clean, and responsive personal note-taking web application. Built to demonstrate state management using React hooks, modern component breakdown, and cutting-edge frontend tooling with **React 19** and the new **Tailwind CSS v4** engine.

---

## ✨ Features

- **Dynamic Note Creation:** Add notes instantly with real-time reactive state updates.
- **One-Click Deletion:** Delete individual notes seamlessly.
- **Responsive Layout:** Grid and flex styling designed to look sharp across mobile, tablet, and desktop screens.
- **Modern UI Styling:** Styled with Tailwind CSS utility classes using `@tailwindcss/vite` integration.
- **Blazing Fast DX:** Powered by Vite 8 for instant Hot Module Replacement (HMR).

---

## 🛠️ Tech Stack

- **Framework:** React 19 (`react`, `react-dom`)
- **Styling:** Tailwind CSS v4 (`@tailwindcss/vite`)

## ⚙️ Installation & Setup

### Prerequisites
* [Node.js](https://nodejs.org/) (v18.x or v20.x recommended)
* npm (bundled with Node.js)

### Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Bhupendra-Kumar-1/react-notes-app.git
   cd react-notes-app
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
